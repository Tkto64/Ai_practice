## Claudeへの基本指示

1. コードを変更する前に、必ず変更の目的と影響範囲を説明してください
2. 既存のファイルを削除する場合は、事前に確認を取ってください
3. テストを自動で実行しないでください。実行前に必ず確認を求めてください
   - テスト実行（例：pytest）
   - ファイル削除
   - 外部通信を伴うコマンド
   - git commit / push
4. コメントは日本語で書いてください

## 禁止事項

- 上記の確認対象を、無断で実行しない
- **絶対にやらないこと**: （例：本番DBへの直接操作、認証情報のハードコード）
- **変更禁止ファイル**: （例：`config/production.yaml`）
- `Project_test/` 外のファイルを編集・削除しない
